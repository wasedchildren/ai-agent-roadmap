# AI Agent 学习路线

面向 AI Agent 应用开发求职与进阶的交互式学习路线。

- 8 周求职冲刺 / 12 周系统进阶
- 六个阶段、二十四项核心任务
- Supabase 邮箱登录与跨设备进度同步
- 用户级 RLS 数据隔离
- 可编辑求职计划目标日期
- 未登录时使用本地保存作为降级方案
- 响应式设计

网站部署完成后访问：<https://wasedchildren.github.io/ai-agent-roadmap/>

## 环境变量

复制 `.env.example` 为 `.env.local`，填写 Supabase Project URL 与 publishable key。前端严禁使用 `service_role` 或 secret key。
